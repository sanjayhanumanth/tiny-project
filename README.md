# Deep Dive

A scroll-driven, immersive static site built with React and Vite. Scroll to sink from the sunlit
surface to the bottom of the Mariana Trench.

## Run it

    npm install
    npm run dev

## What makes it immersive
- Background colour is tied to depth in metres, not page position
- Canvas "marine snow" that drifts up as you descend
- Light rays that fade out below the sunlight zone
- A cursor flashlight that gets darker the deeper you go
- Animated SVG jellyfish and a live depth and pressure gauge
